How to test on the phone

  1. Run the models in an app that works locally, offline (e.g. Google AI Edge Gallery for Gemma 3n, PocketPal AI or llama.cpp in Termux for Bonsai). Use temperature 0 and Top-K 1 if available.
  2. Switch the phone to airplane mode, so it is certain that the model runs offline.
  3. Choose below what the model receives, copy the prompt (it already contains the statement table read by OCR) and paste it into a new chat. The text variants work with any model, so Gemma and Bonsai receive exactly the same input.
  4. Time the answer and note the tokens/s if the app shows them.
  5. Paste the answer here. For the image variant with several pages, separate the answers with a line -----.
